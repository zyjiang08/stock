PDF 第 8～209 页通常对应书内第 1～202 页；第 45、75 页为空白，仍保留原位置；第 210 页是封底。OCR 共识别 119539 个字符，包含页眉页码和图内报价，并非正文净字数。

本次使用本地 RapidOCR / PP-OCRv4；图表文字、公式和转述没有全部逐字校订。置信度不等于实际准确率，关键交易参数须以原图为准。题材评分表和最终交易系统表已人工重排，相关单位冲突和多余文字保留说明。
